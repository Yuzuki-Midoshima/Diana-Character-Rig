# Diana Character Rig

## Installation

1. ZIPを任意の場所へ展開します。
2. Maya 2026を起動します。
3. `drag_drop_install.py` をMayaのViewportへドラッグ＆ドロップします。
4. `Diana Rig` Shelfに **Diana Pivot** と **Equipment** ボタンが作成されたことを確認します。
5. Mayaを再起動します。

インストール後は展開したフォルダーを移動・削除しないでください。移動した場合は、
移動先の `drag_drop_install.py` を再度ドラッグ＆ドロップし、**Reinstall** を選択します。
